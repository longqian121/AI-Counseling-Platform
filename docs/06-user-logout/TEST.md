## 模块6：用户登出 · 测试文档

### TC-6.1 正常登出

| 项目 | 内容 |
|------|------|
| Method | POST /api/user/logout |
| 鉴权 | 需登录 |
| 预期 | 200，返回成功 |
| 验证点 | 前端收到响应后清除 token，跳转到登录页 |

### TC-6.2 未登录调用

| 项目 | 内容 |
|------|------|
| 前置条件 | 无 token |
| 步骤 | POST /api/user/logout |
| 预期 | 401 Unauthorized |

### TC-6.3 登出后 token 仍可访问（已知行为）

| 项目 | 内容 |
|------|------|
| 前置条件 | 用户登出，前端清除 token |
| 步骤 | 用旧的 token 手动调用任意需登录接口 |
| 预期 | 接口仍然可用（JWT 无状态，token 未过期） |
| 说明 | 这是 JWT 固有特性，当前阶段不实现黑名单 |

### TC-6.4 前端 admin.js logout() 调用验证

| 项目 | 内容 |
|------|------|
| 前置条件 | 后端 /api/user/logout 已实现 |
| 步骤 | 管理端点击退出登录 |
| 预期 | 前端调用 logout() → 收到 200 → 清除 token → 跳转登录页 |
