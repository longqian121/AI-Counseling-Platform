## 1. 功能概述

为心理医生（user_type=3）提供独立的登录入口和工作台，用于查看和管理分配给自己的预约。医生可以通过现有登录页面登录，系统根据 user_type 自动路由到医生工作台。

## 2. 用户故事

> 作为心理医生（李辉），我在登录后能看到今天的预约列表，能标记预约为"已完成"，
> 能查看历史预约记录，以便高效管理日常接诊工作。

## 3. 角色与登录

### 3.1 数据关联

现有 counselor 表和 user 表之间没有关联。需要新增关联：

| 改动 | 说明 |
|------|------|
| counselor 表新增 user_id 字段 | 用于关联 user 表中的医生账号 |
| user 表已有 user_type=3（心理医生） | 上一阶段已添加 COUNSELOR 枚举 |

- 一个 user（user_type=3）对应一个 counselor 记录
- 登录时通过 counselor.user_id 查找对应的医生信息

### 3.2 登录流程

1. 医生使用管理员分配的账号（user_type=3）在 /auth/login 登录
2. 前端路由守卫根据 userInfo.userType == 3 → 重定向到 /doctor
3. /doctor 使用独立的 DoctorLayout

## 4. 医生工作台功能

### 4.1 今日预约

- 默认展示当天所有属于该医生的预约（appointment.counselor_id = 当前医生的 counselor.id）
- 列表列：患者昵称、时间段、状态、备注
- 状态为"已预约"的记录显示"标记完成"按钮

### 4.2 全部预约

- 可按日期范围筛选
- 可按状态筛选（已预约 / 已完成 / 已取消）

### 4.3 标记完成

- 医生可将"已预约"的预约标记为"已完成"（status 1→2）
- 需要二次确认

## 5. 页面入口

| 位置 | 说明 |
|------|------|
| URL | /doctor 重定向到 /doctor/dashboard |
| 布局 | 新建 DoctorLayout，左侧简洁导航 + 右侧内容区 |
| 导航项 | 今日预约、全部预约 |

## 6. 非功能需求

- 仅 user_type=3 可访问 /doctor/* 路由
- 医生只能看自己的预约
- 列表分页 10 条/页
