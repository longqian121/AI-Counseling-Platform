## 1. 数据库改动

### 1.1 counselor 表新增 user_id

```sql
ALTER TABLE counselor ADD COLUMN user_id BIGINT AFTER id;
ALTER TABLE counselor ADD INDEX idx_user_id (user_id);
```

### 1.2 Counselor.java 实体更新

新增字段：
```java
@TableField("user_id")
private Long userId;
```

## 2. 后端接口设计

### 2.1 DoctorController

| 端点 | 方法 | 说明 |
|------|------|------|
| /api/doctor/appointments/today | GET | 今日预约列表（自动获取当前医生的 counselorId） |
| /api/doctor/appointments | GET | 全部预约（支持日期范围+状态筛选） |
| /api/doctor/appointment/{id}/complete | PUT | 标记预约已完成 |

### 2.2 医生身份获取流程

1. 从 JWT 中提取 userId
2. 通过 counselorMapper.getByUserId(userId) 查找对应的 counselor 记录
3. 以 counselor.id 作为过滤条件查询 appointment

### 2.3 CounselorMapper 新增方法

```java
@Select("SELECT * FROM counselor WHERE user_id = #{userId}")
Counselor getByUserId(@Param("userId") Long userId);
```

### 2.4 AppointmentMapper 新增方法

```java
@Select("<script>" +
    "SELECT a.*, u.nickname AS userNickname FROM appointment a " +
    "LEFT JOIN user u ON a.user_id = u.id " +
    "WHERE a.counselor_id = #{counselorId} " +
    "<if test='params.dateFrom != null'>AND a.appointment_date >= #{params.dateFrom}</if> " +
    "<if test='params.dateTo != null'>AND a.appointment_date <= #{params.dateTo}</if> " +
    "<if test='params.status != null'>AND a.status = #{params.status}</if> " +
    "ORDER BY a.appointment_date DESC, a.time_slot ASC" +
    "</script>")
IPage<Appointment> getDoctorAppointments(Page<?> page,
        @Param("counselorId") Long counselorId,
        @Param("params") Map<String, Object> params);
```

### 2.5 AppointmentService

新建服务层，封装医生端预约管理逻辑：
- getTodayAppointments(counselorId)
- getDoctorAppointments(counselorId, params)
- completeAppointment(id, counselorId) ― 校验归属 + 状态变更

## 3. 前端实现

### 3.1 路由改动

在 router/index.js 中新增：
```js
{
    path: '/doctor',
    redirect: '/doctor/dashboard',
    component: DoctorLayout,
    children: [
        { path: 'dashboard', component: () => import('@/views/doctorDashboard.vue'),
          meta: { title: '今日预约', icon: 'Clock' } },
        { path: 'appointments', component: () => import('@/views/doctorAppointments.vue'),
          meta: { title: '全部预约', icon: 'List' } }
    ]
}
```

路由守卫新增 user_type=3 判断：
```js
if (userInfo.userType == 3) {
    if (to.path.startsWith('/doctor')) next()
    else next('/doctor/dashboard')
}
```

### 3.2 新增文件清单

| 文件 | 说明 |
|------|------|
| DoctorLayout.vue | 医生端布局（左侧导航+顶栏+内容区） |
| doctorDashboard.vue | 今日预约页 |
| doctorAppointments.vue | 全部预约管理页 |
| api/doctor.js | 医生端 API 封装 |

### 3.3 注意

- 登录页面 /auth/login 不变，所有角色共用
- 医生登录后的跳转由路由守卫自动处理
- SecurityConfig 需放行 /api/doctor/** 给 user_type=3
