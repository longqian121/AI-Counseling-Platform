## 1. 功能概述

普通用户在心理支持聊天之外，需要一个独立页面查看自己的预约状态，包括已预约、已完成、已取消的记录，并支持取消待进行的预约。

## 2. 用户故事

> 作为普通用户，我想在"我的预约"页面看到所有预约记录（医生姓名、日期、时段、状态），
> 并能取消还未完成的预约，这样我能统一管理自己的咨询安排。

## 3. 页面入口

| 位置 | 说明 |
|------|------|
| 导航栏 | 在现有"心理支持""情绪日记""知识科普"旁边新增"我的预约"入口 |
| URL | /appointments |
| 布局 | 复用 FrontendLayout（和现有用户端页面一致） |

## 4. 页面功能

### 4.1 预约列表

| 列 | 数据来源 | 说明 |
|-----|----------|------|
| 医生姓名 | appointment JOIN counselor | 显示 counselor.name |
| 职称 | appointment JOIN counselor | 显示 counselor.title |
| 预约日期 | appointment.appointment_date | yyyy-MM-dd 格式 |
| 时间段 | appointment.time_slot | 如 14:00-15:00 |
| 状态 | appointment.status | 已预约 / 已完成 / 已取消 |
| 备注 | appointment.remark | 用户预约时填写的备注 |
| 操作 | ― | 已预约的记录显示"取消预约"按钮 |

### 4.2 取消预约

- 仅状态为"已预约"(status=1) 的记录可取消
- 点击"取消预约"弹出确认框
- 确认后将 status 改为 0，记录 cancel_reason 为"用户主动取消"
- 取消后刷新列表

### 4.3 权限控制

- 仅登录用户（user_type=1）可访问
- 仅返回当前用户的预约记录
- 仅允许取消自己的预约
